# ESP recorder
Firmware for a ESP32-based audio review recorder and desk lamp hybrid. Developed using PlatformIO & Arduino-Espressif as the base framework.

# Features
- A microphone for recording audio reviews;
- Button to start the recording. Press-n-hold mode;
- Audio file upload to a remote FTP server;
- Audio recordings storage on an external SD card in case of no internet connection with free space managing;
- E-paper screen on SPI for communication with the user;
- WS2812 LED controlling;
- Rotary encoder to change LED brightness;
- External RTC & SNTP time syncronization;
- Power-saving mode;
